隐私政策

版本：1.0.7 | 最后更新：2026年8月14日

开发者： LUKONICHEV DMITRII

本隐私政策描述了由 LUKONICHEV DMITRII（以下简称"开发者"）开发的应用程序"物品清单"（以下简称"本应用"）如何处理用户信息。

1. 信息的收集和使用

本应用本身不收集也不向开发者传输用户所创建列表的内容。所有列表、项目名称及其数量均存储在设备本地。

2. 广告

为了维持免费版本，本应用可能使用 Petal Ads（华为）和 Yandex Mobile Ads 广告 SDK。

广告 SDK 可能处理设备的技术信息以及展示广告、衡量广告效果和个性化广告所需的数据。根据所使用的 SDK 和设备设置，可能会处理与广告标识符、设备特征、广告互动及其他技术参数相关的信息。

数据由相应的广告服务提供商根据其隐私政策进行处理。

华为隐私政策：consumer.huawei.com/privacy

Yandex 隐私政策：yandex.com/legal/confidential/

Yandex Mobile Ads 支持 GDPR 要求；对于欧洲经济区和瑞士的用户，相关 SDK 数据的处理应考虑到用户的同意。

3. 用户权利

您可以随时通过您操作系统的标准方式删除本应用。删除后，您在本应用中创建的所有列表、项目和设置将被删除。已通过广告 SDK 传输的数据将按照相应提供商的隐私政策处理，且无法通过删除应用来删除。

您也可以随时通过设备设置清除本应用数据，或通过禁止应用访问设备中的广告标识符来撤回您的同意。

4. 政策变更

我们可能会不时更新本政策。建议您定期查看此页面。
